## 收錄的八個模組

1. Surface AOI Inspector — 表面瑕疵檢測與融合判定
2. RTSafe Sensor Hub — 1 kHz 感測、安全狀態機與遙測
3. Demand Planning Workbench — 回測選模、預測區間與情境規劃
4. KnowledgeOps Studio — 多模型 Gateway、PromptOps 與品質治理
5. SimOps Studio — PCB／PDN／SPICE 工程模擬
6. OpenFund Risk Workbench — 金融 ML、風險評分與監控
7. OpsFlow Agent — 有引用、可拒答、可人工接手的 RAG 工作流
8. Retail Data Hub — SQL／ETL、資料契約與品質閘門

- 一鍵整線事件演練：從力量突波一路追到排程重算

- 金融壓力與 EDA 運算負載互動模擬
- 有引用、證據分數、拒答與人工分流的 RAG 示範
- AI 版本評測實驗室：24 題黃金題集、版本比較、退步閘門與發布
- 營運知識圖譜：追查資產、批次、Trace、配方、政策、SOP、決策、任務與交班記憶的關係
