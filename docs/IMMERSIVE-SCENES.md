## 體驗與互動

- AOI：真實立體幾何的輸送帶、移動工件、相機門架、掃描光與控制箱。停留時持續運作。
- 工件與監看畫面共用時間及情境資料。正常品、明顯刮痕、人工複核分別顯示 OK、NG、REVIEW；不使用虛構準確率。
- RTSafe：具關節的機械臂、安全節點、控制箱與力量／心跳監看。力量超限與心跳遺失會凍結運動姿態，選擇正常运轉才繼續。
- 模型表面取樣的光點在章節間拆散、漂浮、聚合。反向滾動能回到上一個完整模型。
- 滑鼠小幅視角偏移、設備說明、暫停運作、放大監看、鍵盤焦點與 Escape 關閉。
- 「減少動態」尊重裝置設定，也提供頁面開關；改成完整靜態關鍵姿態並取消長距離黏性段落。
- 窄螢幕重新排列標題、模型、監看；短手機視窗使用簡化切站方式。WebGL 失敗時保留原創 SVG 示意與可讀內容。

## 場景契約

進度為展示區自己的正規化滾動進度，不是整頁百分比。

| 進度 | 場景 | 運作 |
| --- | --- | --- |
| 0–0.24 | AOI 定點 | 輸送帶與工件持續移動 |
| 0.24–0.70 | 分解／漂浮／組合 | 設備時鐘暫停；光點漂浮時鐘持續 |
| 0.70–1 | RTSafe 定點 | 正常時持續運動；故障時停在當前姿態 |

滾動映射為純函式；上、下方向使用同一套計算。沒有攔截滾輪或強迫吸附。點擊導覽移到定點，瀏覽器返回／前進可恢復場景。

- **本作改編**：依工程作品設計原創輸送線、安全站及表面粒子；使用灰綠／奶白工業模型、深色監看、彩色流光。沒有複製無人機、品牌、文案或模型素材。

沿用本機 Three.js 0.180.0，沒有增加外部下載依賴。粒子數在初始化時依視窗選擇桌面 8,000／手機 3,200。進入轉場才重採樣當前模型姿態；不是每幀重新取樣。頁面隱藏或舞台離開視窗時暫停連續渲染。

擴展下一座場景時需同步新增：可辨識的幾何、定點持續動作、至少一個有意義的情境操作、證據／監看畫面、靜態示意、明確模擬標示與反向轉場測試。不要只替换名稱或顏色。

## 驗證紀錄

自動測試：原有 22 項加新增 14 項，合計 36 項通過；原工作台核心指紋測試仍通過。新增內容涵蓋穩定區間、邊界、雙向對稱、非法輸入、減少動態、工件一致性、三種 AOI 判定、安全異常、靜態 HTML、資源路徑與唯一 ID。

本機 Chrome 實際 UI 操作：

- 桌面 1920×959、1440×900；手機尺寸模擬 390×844。
- 首屏模型、向下分解、光點、下一站與向上重組。
- 三種 AOI 情境會更新判定；鍵盤 Enter 可操作。
- 力量超限與心跳遺失原因分開顯示；力量超限時多次讀取的機械臂角度及時間維持相同。
- 放大安全訊號畫面、Escape 關閉及焦點返回。
- 暫停時模擬時間不前進；減少動態時取消長舞台、沒有轉場粒子，導覽仍能切換。
- 手機無橫向溢出；改變視窗尺寸時維持當前進度。
- 實測瀏覽器返回至 AOI 約 0.08，前進至 RTSafe 約 0.84；修正原生捲動位置恢復與場景定位競爭造成停在轉場中途的問題。
- 最後一次檢查未收到瀏覽器 warning／error。

本輪修正：SVG 的 hidden 狀態同步、放大 SVG 的重複 ID、手機標題斷行、模型與按鈕重疊、縮放視窗的進度跳動，以及轉場時模型畫布大小驟變。

### 尚未驗證／限制

- 手機為桌面瀏覽器視窗模擬，尚未做實體 iOS／Android 裝置測試。
- 無 JavaScript 的內容／資源由文件契約檢查；尚未做瀏覽器關閉 JavaScript 及刻意 WebGL context loss 的 UI 測試。
- 未建立實體裝置的 FPS、GPU 記憶體、耗電與弱網效能基準。測試環境曾觀察到慢幀；不能宣稱全裝置 60 FPS。
- 沒有重新執行舊版全部 Windows／歷史瀏覽器驗證；舊紀錄不代表本次新頁已通過那些檢查。
- 所有工件、瑕疵、感測數值與設備行為都是合成展示，不連接相機、機械臂或安全控制器；不代表真實檢測精度、安全認證或硬體時限。
