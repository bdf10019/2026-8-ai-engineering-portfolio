# Windows 單一執行檔

`2026_8月合輯.exe` 將靜態網站、3D 素材、證據與 PDF 直接內嵌於 EXE。執行時從記憶體提供檔案，不需要 Node.js、模型權重下載或安裝程序。

雙擊後自動開啟系統預設瀏覽器。右下角 AXIS-09 圖示可再次開啟網頁、分鏡或結束服務。再次雙擊 EXE 會通知原執行個體開啟網頁，不建立第二份服務。

環境：Windows 10／11，使用隨系統提供的 .NET Framework 4.x，以及支援 WebGL 2 的現代瀏覽器。減少動態或 WebGL 不可用時仍可讀取靜態版本。

服務只綁定 `127.0.0.1`，預設連接埠 18409；若被占用，改用作業系統提供的空閒連接埠。只提供內嵌的唯讀檔案，支援 GET、HEAD 與單段 Range；不提供任意磁碟存取或遠端操控。

執行個體資訊保存在 `%LOCALAPPDATA%/AXIS09/instance.json`，正常從圖示結束時移除。使用者在工作台的偏好與情境由瀏覽器保存在本機；原有來源資料不寫入 EXE。

建置：安裝 PowerShell 7，在原始碼根目錄執行 `pwsh -File tools/build-windows.ps1`，遵循電腦既有的指令碼執行原則。產物為 `dist/2026_8月合輯.exe` 與 `dist/SHA256SUMS.txt`。EXE 未包含程式碼簽章；對外發行時可另以自己的憑證簽署，並重新產生雜湊。

`--no-browser` 僅供自動化 HTTP 冒煙測試：啟動服務但不自動打開瀏覽器。正常使用直接雙擊即可。
